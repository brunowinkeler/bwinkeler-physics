# Content sources

## Native simulation repository

- Repository: https://github.com/brunowinkeler/cpp-physics-simulation
- Retrieval: exact Git submodule revision
- Used for: physics source, supported controls, implementation facts, dependency versions, and canonical theory documents

Every release must record the submodule SHA. Theory is rendered directly from
`project*/PHYSICS_THEORY.md`; it must not be copied into a second maintained web
document.

## Publication policy

- All public UI and documentation is English.
- Equations, units, assumptions, and validation claims must remain traceable to
  the canonical source or a reviewed scientific reference.
- Performance claims require measurements on identified hardware and browsers.
- Do not claim a universal native-to-WebAssembly performance ratio.
- Screenshots and project descriptions must not expose confidential information.
